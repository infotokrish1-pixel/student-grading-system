# Task 1: Student Grading System

## 📋 Project Description
This is a console-based Java application developed for my internship assignment (Task 1). The program provides an efficient way for educators to input, manage, and analyze student grades dynamically. It stores student names alongside their scores and automatically generates a detailed performance report.

## ✨ Core Features
* **Dynamic Management:** Uses `ArrayList` to store and manage an unlimited number of student profiles seamlessly.
* **Automated Analytics:** Instantly calculates critical metrics including class average, highest score, and lowest score.
* **Input Validation:** Employs robust error and exception handling to reject invalid entries (out-of-range marks or non-numeric inputs).
* **Summary Report:** Displays a clean, structured tabular layout showcasing all student records and final analytics.

## 🛠️ Tech Stack & Concepts
* **Language:** Java (JDK 17+)
* **Core Concepts:** Object-Oriented Programming (OOP), ArrayLists, Scanner Class (I/O operations), and Exception Handling.

## 🚀 How to Run
1. Download or clone this repository.
2. Open the source file `StudentGradingSystem.java` in any Java IDE (e.g., IntelliJ, Eclipse, VS Code).
3. Compile and run the program.
4. Follow the console prompts to enter names and scores. Type `exit` to finalize inputs and view the summary report.
